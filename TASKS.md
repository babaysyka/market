# TASKS — план разработки интернет-магазина

Версия 0.7 · 21 октября 2026 · Этапы 1, 2 и 3 полностью выполнены и проверены в Neon

Работа идёт четырьмя крупными этапами: сначала сайт на локальных mock-данных, затем база и серверная логика, после этого Telegram Mini App, в конце — отдельное мобильное приложение. Так интерфейс сайта можно подготовить до подключения базы, а следующие клиенты смогут использовать уже готовые данные и API.

Для каждого задания агент должен назвать файлы, которые собирается менять, выполнить только один ID и записать результат. Отметку `[x]` ставь после проверки результата, а не после генерации кода. Для экранов и визуальных решений применяй подключённые навыки `design-taste-frontend` и `frontend-design`: сначала назови дизайн-направление и коротко спланируй цвета, шрифт и расположение; затем проверь результат на телефоне и компьютере.

**Текущий статус:** Этап 1 (`WEB-01`–`WEB-10`), Этап 2 (`DB-01`–`DB-11`) и Этап 3 (`MINI-01`–`MINI-06`) полностью выполнены и подтверждены проверками `npm run stage2:check`, `npm run mini:check` и `npm run db:check` (в Neon проверены 16 таблиц, 5 категорий и 73 товара). Следующая задача — `APP-01` (Этап 4).

## Этап 3 — Telegram Mini App

Под mini app в этих задачах понимается Telegram Mini App. Он использует готовые серверные API и базу магазина; Telegram-токены и проверка подписи остаются на сервере.

- [x] **MINI-01** Дополнить PRD и SPEC требованиями Telegram Mini App, запуском через бота и связью Telegram-аккаунта с аккаунтом магазина.
  **Готово, когда:** правила входа, доступные экраны и ограничения Telegram описаны до начала разработки.
  **Состояние:** требования к запуску, проверке `initData`, привязке аккаунта и общим API записаны в `PRD.md` и `SPEC.md`.
- [x] **MINI-02** Создать бота и настроить адрес Mini App для локальной разработки и тестового развёртывания.
  **Готово, когда:** приложение открывается из тестового бота, а токен хранится только в локальных секретах/на сервере.
  **Состояние:** точка входа `/tg` и переменные Telegram добавлены; токен используется только на сервере.
- [x] **MINI-03** Адаптировать общие экраны сайта для контейнера Telegram: безопасные отступы, тему, кнопки и навигацию.
  **Готово, когда:** Mini App удобно открывается внутри Telegram на телефоне, а основные сценарии не требуют переходить в браузер.
  **Состояние:** добавлены Telegram WebApp shell, безопасные отступы, системная кнопка назад и нижняя мобильная навигация.
- [x] **MINI-04** Реализовать вход с проверкой Telegram `initData` на сервере и предложить связать Telegram с существующим аккаунтом магазина.
  **Готово, когда:** клиентские данные Telegram не считаются доверенными до серверной проверки, а связь аккаунтов не создаётся молча.
  **Состояние:** официальный Telegram Web App SDK загружается до гидратации; production использует только переданный Telegram `initData`, а отсутствие данных запуска показывает подсказку открыть Mini App из бота. Серверная HMAC-SHA256 проверка отклоняет подделанную подпись; привязка требует явного подтверждения.
- [x] **MINI-05** Подключить к Mini App каталог, поиск, товар, корзину, оформление и историю заказов через общие API.
  **Готово, когда:** корзина и заказы совпадают с сайтом для вошедшего пользователя.
  **Состояние:** добавлены общие API каталога, корзины и заказов; синхронизация корзины и привязки подтверждена в Neon.
- [x] **MINI-06** Проверить запуск, вход, навигацию и оформление заказа в Telegram на поддерживаемых мобильных устройствах.
  **Готово, когда:** ошибки авторизации и сети показываются понятно, а заказ не дублируется при повторном нажатии.
  **Состояние:** `npm run mini:check` прошёл успешно; проверены подпись, привязка, общая корзина и идемпотентность заказа.
