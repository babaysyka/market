# ЭлектроМаркет

Интернет-магазин электроники и техники для дома. Витрина наполнена локальным каталогом товаров, ценами, рейтингами и заказами; серверные аккаунты, хранение каталога и приём оплаты подключаются отдельно.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для проверки production-сборки выполните `npm run build`.

## Локальная база

Скопируйте `.env.example` в `.env.local` и задайте `DATABASE_URL` строкой подключения из панели Neon. Переменная нужна только серверу и не должна начинаться с `NEXT_PUBLIC_`. Проверьте соединение командой `npm run db:check`.

Схема таблиц и первая миграция добавляются на следующем этапе DB-02.

План требований и этапов находится в `../PRD.md`, `../SPEC.md` и `../TASKS.md`.
